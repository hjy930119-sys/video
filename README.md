# Frame Studio 0.2 — 마우스로 편집하는 Windows 영상 편집기

영상을 여러 개 이어 붙이고, 자막·이미지·다른 영상을 겹쳐 MP4로 만드는 로컬 프로그램입니다. Windows 10/11 x64용입니다.

## ZIP 받기와 바탕화면 아이콘

1. https://github.com/hjy930119-sys/video/actions 에서 **Build Windows ZIP**의 성공한 최신 작업을 엽니다.
2. 아래 **Artifacts → Frame-Studio-Windows**를 클릭해 ZIP을 받습니다. GitHub 로그인이 필요합니다.
3. ZIP을 **모두 압축 풀기** 합니다.
4. **Frame-Studio-0.2.0-Setup.exe**를 실행하면 설치 위치를 선택하고 바탕화면·시작 메뉴 아이콘을 만들 수 있습니다.
5. 설치 없이 쓰려면 **Portable.exe**를 실행합니다. 앱 상단 **바탕화면 아이콘** 버튼으로 바로가기도 만들 수 있습니다. 포터블 파일을 나중에 옮기면 바로가기를 다시 만들어 주세요.

Node.js나 FFmpeg를 따로 설치할 필요가 없습니다. 이 개발 빌드에는 코드 서명이 없습니다. Actions ZIP은 90일 동안 보관하며 만료되면 **Run workflow**로 다시 만들 수 있습니다. **Code → Download ZIP**은 실행 파일이 없는 소스 ZIP입니다.

## 기본 편집

- **영상 이어붙이기**: 탐색기의 영상 여러 개를 왼쪽이나 아래 타임라인에 끌어놓습니다. 파일 선택 창에서도 여러 개를 선택할 수 있습니다. 영상이 뒤에 차례로 추가됩니다. 첫 영상이 세로면 세로 출력이 선택됩니다.
- **순서 변경**: 왼쪽 영상 카드를 끌어 다른 카드 앞에 놓거나, 영상 선택 후 오른쪽 **앞 순서 / 뒤 순서** 버튼을 사용합니다.
- **앞뒤 탐색**: 타임라인 눈금·빈 공간을 누르거나 밝은 재생헤드를 드래그합니다. 클립 몸통을 누르면 선택만 하고 재생 위치는 유지합니다. 재생 중 탐색하면 새 위치부터 이어 재생합니다.
- **타임라인 확대/스크롤**: 확대 슬라이더, Ctrl+마우스 휠, **전체 보기**를 사용합니다. 가로 스크롤바·Shift+휠·가로 휠로 이동합니다. Alt+드래그 또는 휠 버튼 드래그로 화면을 밀 수도 있습니다.
- **자르기**: 타임라인 영상 클립의 양끝 손잡이를 끌거나 오른쪽 원본 시작/끝을 입력합니다. 뒤 영상이 자동으로 붙습니다. 자른 구간은 다시 늘려 복구할 수 있으며 원본은 바뀌지 않습니다.
- **중간 잘라내기**: 잘라낼 구간의 앞뒤에서 각각 **✂ 분할** 후 가운데 클립을 선택하고 **삭제**합니다. 실행 취소로 되돌릴 수 있습니다.
- **복제**: 선택한 클립·레이어를 복제할 수 있습니다.

타임라인은 30fps 기준입니다. 영상 클립 길이와 분할은 출력 프레임에 맞춰 반올림됩니다. 자막·이미지·삽입 영상의 시간은 최종 프로젝트 전체 기준이며 원본 영상의 시간과 다릅니다. 기본 영상 순서나 길이를 바꿔도 레이어는 전체 타임라인의 위치를 유지합니다. 전체 길이를 줄여 범위를 벗어나면 레이어가 줄어들거나 제거되므로 필요하면 실행 취소 후 레이어 시간도 조정하세요.

## 자막·이미지·영상 속 영상

1. **자막**, **이미지/로고**, **영상 속 영상** 버튼으로 추가합니다. 미리보기 화면 위에 이미지·영상 파일을 끌어놓아도 됩니다. 영상이 없는 첫 화면에 놓은 영상은 기본 영상으로 들어갑니다.
2. 미리보기에서 항목을 눌러 선택하고 **마우스로 끌어 위치를 옮깁니다.** 오른쪽 아래의 밝은 모서리를 끌면 비율을 유지하며 크기가 바뀝니다. 숫자 입력도 가능합니다.
3. 레이어의 타임라인 몸통을 끌면 표시 시간이 이동합니다. 양끝 손잡이를 끌면 시작/끝을 조절합니다. 영상 레이어의 왼쪽을 자르면 삽입 영상의 원본 시작도 함께 잘립니다.
4. **자석 맞춤**으로 다른 클립 끝·재생헤드와 시간을 맞출 수 있습니다. 미리보기에서는 화면 중앙에 맞춰집니다.
5. 자막은 PC의 설치 글꼴, 크기, 색, 굵기를 선택할 수 있습니다. 글꼴을 새로 설치했다면 앱을 다시 실행하세요. 한글 글꼴(예: 맑은 고딕)을 선택하면 한글 표시가 자연스럽습니다.
6. 이미지와 삽입 영상은 폭·불투명도를 조절할 수 있습니다. PNG 투명 배경을 지원합니다. 삽입 영상은 기본 무음이며 음량을 올리면 원본 음성도 함께 저장됩니다.
7. 목록에서 아래쪽 레이어가 위에 표시됩니다. **뒤로 / 앞으로**로 겹치는 순서를 변경합니다.

새 자막·레이어는 현재 재생 위치에서 시작합니다. 현재 위치가 표시 구간 밖이면 해당 레이어가 보이지 않으므로 타임라인의 표시 구간 안으로 이동하세요. 화면 밖으로 크게 배치한 항목은 출력 화면 경계에서 잘립니다.

## 페이드와 음악

선택한 영상·자막·이미지·삽입 영상에 페이드인/아웃 시간을 입력하거나 **부드럽게 0.5초**를 누릅니다. 기본 영상은 검정 화면에서 나타나거나 사라지고, 겹치는 레이어는 투명하게 나타나거나 사라집니다. 영상 음성에도 페이드가 적용됩니다. 클립 사이를 겹쳐 섞는 크로스 디졸브 전환은 포함하지 않습니다.

배경음악은 전체 영상 길이에 맞춰 반복됩니다. 원본 클립·삽입 영상·배경음악의 음량을 각각 조절할 수 있으며 배경음악에도 페이드인을/아웃을 적용할 수 있습니다. 저장 시 과도한 음성 피크를 제한합니다. 미리보기와 저장 음량은 이 제한 처리 때문에 조금 다를 수 있습니다.

## 저장과 실수 복구

- **MP4 저장**: 모든 영상·자막·이미지를 한 영상으로 합칩니다. 진행률과 취소 기능이 있습니다.
- **프로젝트 저장**: 편집 상태를 JSON으로 저장합니다. 원본 파일은 포함하지 않으니 원본을 이동하지 마세요. 이전 0.1 프로젝트도 열어 변환할 수 있습니다.
- **실행 취소/다시 실행**: 최대 60단계의 편집 상태를 되돌립니다. 클립 삭제·순서 변경·드래그·글자 변경도 포함합니다.
- **자동 복구**: 변경된 프로젝트는 15초마다 사용자 데이터 폴더에 복구 사본을 저장합니다. 다음 실행 시 복구 여부를 묻습니다. 직접 저장도 함께 사용하는 것을 권장합니다.

단축키: Space 재생/정지, ←/→ 한 프레임, Shift+←/→ 1초, Home/End 처음/끝, S 분할, Delete 삭제, Ctrl+D 복제, Ctrl+Z 취소, Ctrl+Shift+Z 또는 Ctrl+Y 다시 실행, Ctrl+S 저장. 글자 입력 중에는 편집기의 단축키 대신 입력 필드가 우선합니다(Ctrl+S 제외).

## 호환 범위

- 기본 영상 최대 100클립, 겹치는 레이어 최대 100개, 전체 최대 24시간을 검증합니다. 실제 처리 성능은 PC와 해상도에 따라 달라집니다.
- 미리보기에는 H.264 MP4가 가장 호환성이 좋습니다. 일부 HEVC·MKV·특수 코덱은 저장 가능해도 미리보기가 재생되지 않을 수 있습니다.
- 1080p 가로·세로·정사각형 및 720p 출력, 30fps H.264/AAC MP4를 제공합니다. 화면비가 다르면 검정 여백을 넣습니다. HDR 보존과 자동 색상 관리는 제공하지 않습니다.
- 설치된 TTF/OTF/TTC 글꼴을 로컬에서 읽습니다. 일부 오래된 비트맵 글꼴이나 특수 글꼴은 대체될 수 있습니다. Chromium과 FFmpeg의 글꼴 렌더링 차이로 자간·행간이 약간 다를 수 있습니다.
- 자동 음성 자막, 속도 조절, 자유 곡선 키프레임, SRT 입출력은 이번 버전에 포함하지 않습니다.

## 개발 및 검증

Node.js 24에서 `npm ci`, `npm start`로 실행합니다. `시작.bat`도 사용할 수 있습니다. Windows에서 `npm run dist:win`으로 설치판과 포터블판을 함께 만듭니다.

`npm test`는 실제 FFmpeg MP4를 생성해 서로 다른 해상도·프레임률·음성 유무의 이어붙이기, 프레임 단위 자르기, 영상 레이어, 이미지, 글꼴 지정 자막, 페이드, 배경음악 반복과 프로젝트 변환을 검사합니다.

`node test/ui-check.cjs`는 Chromium으로 파일 추가, 선택 시 위치 유지, 앞뒤 탐색, 손잡이 자르기, 분할, 실행 취소/다시 실행, 카드 순서 변경, 글꼴 선택, 화면 드래그·크기 조절, 파일 드롭, 복구 저장, 다시 열기 및 내보내기 흐름을 검사합니다. 파일 접근 API는 모의 구현이며 렌더링은 별도 FFmpeg 테스트가 검증합니다. 로컬 Chromium 경로는 `CHROMIUM_PATH`로 설정할 수 있습니다. 샘플 MP4/PNG가 없으면 테스트 코드가 FFmpeg로 자동 생성합니다.

GitHub Windows CI는 실제 FFmpeg 통합 테스트, Electron·preload 초기화, 앱 전용 미디어 주소에서 실제 프레임 탐색과 Canvas 픽셀 읽기, 설치판 생성·무인 설치, 바탕화면 바로가기 경로와 설치된 앱 실행을 검증합니다. 최종 성공 여부는 해당 Actions 실행 로그를 확인하세요. 실제 사용자 PC의 긴 영상과 다양한 코덱·글꼴은 추가 사용 검증이 필요합니다.

사용 방식 설계에는 [OpenShot 공개 기능 목록](https://github.com/OpenShot/openshot-qt)과 [Shotcut 프로젝트 자료](https://github.com/mltframework/shotcut)를 참고했습니다. 해당 프로젝트의 코드를 가져오지는 않았습니다.

앱 소스는 MIT입니다. FFmpeg 및 기타 구성요소 라이선스는 THIRD_PARTY.md와 번들 라이선스를 따릅니다.
