# Frame Studio 0.1 — Windows 영상 편집기

Windows 10/11 x64용 로컬 영상 편집기 초기 버전입니다.

## ZIP 다운로드

1. https://github.com/hjy930119-sys/video/actions 를 엽니다.
2. **Build Windows ZIP**의 초록색 체크가 있는 최신 작업을 클릭합니다.
3. 아래 **Artifacts**에서 **Frame-Studio-Windows**를 클릭합니다. GitHub 로그인이 필요합니다.
4. 내려받은 ZIP을 **모두 압축 풀기**한 다음 EXE를 실행합니다.

Actions 산출물은 90일 동안 보관합니다. 만료되면 Actions → Build Windows ZIP → Run workflow로 다시 만들 수 있습니다. 소스의 Code → Download ZIP에는 실행 파일이 없으므로 반드시 Actions에서 받으세요.

## 가장 쉬운 실행

`Frame-Studio-0.1.0-Windows.exe`를 Windows PC의 폴더에 저장하고 실행하세요.
설치가 필요 없는 포터블 앱이며 영상 처리 도구인 FFmpeg가 포함됩니다.
별도로 Node.js나 FFmpeg를 설치할 필요가 없습니다. 실행 파일은 코드 서명이 없는 개발 빌드입니다.

1. **영상 불러오기**로 영상을 선택합니다. 미리보기 호환성을 위해 H.264 MP4를 권장합니다.
2. 오른쪽 **구간 시작/끝**으로 내보낼 구간을 초 단위로 지정합니다.
3. **자막 추가**를 누르고 내용, 표시 시간, 위치, 글자 크기와 색을 조절합니다. 여러 자막과 줄바꿈을 지원합니다.
4. **이미지 추가**로 PNG/JPG/WebP를 불러옵니다. 표시 시간, 위치, 크기, 불투명도를 조절합니다. PNG 투명 배경을 지원합니다.
5. 자막과 이미지를 여러 개 추가할 수 있습니다. 목록의 마지막 레이어가 위에 표시됩니다. 뒤로/앞으로 버튼으로 겹치는 순서를 바꿉니다.
6. 필요하면 **배경음악 불러오기**를 누릅니다. 음악은 편집 구간의 시작부터 반복 재생됩니다. 원본 음성과 음악의 음량을 각각 조절할 수 있습니다.
7. **MP4 내보내기**에서 저장 위치를 정합니다. 진행률을 확인하거나 취소할 수 있습니다.
8. 작업을 이어 하려면 **프로젝트 저장**을 사용하고, 다음에 **프로젝트 열기**를 누릅니다.

시간은 모두 **원본 영상의 시간**입니다. 예를 들어 구간을 10~20초로 자른 뒤 자막을 12~15초로 지정하면, 저장한 영상에서는 2~5초에 자막이 나옵니다.
이미지 위치는 왼쪽 위 모서리, 자막 위치는 위쪽 가운데를 기준으로 합니다. 이미지 폭은 출력 영상 폭에 대한 비율입니다.
출력 화면비가 다르면 원본 영상 전체가 보이도록 검정 여백이 들어갑니다. 자막·이미지는 그 출력 화면을 기준으로 배치됩니다.

## 첫 버전의 범위

한 개의 원본 영상에서 시작/끝을 잘라 내보내는 편집과 다중 자막·이미지 합성을 제공합니다.
여러 영상 이어 붙이기, 클립 중간 분할·순서 변경, 자동 음성 자막, 전환 효과, 이미지 드래그 편집, 실행 취소는 아직 구현하지 않았습니다.
프로젝트 파일은 원본을 포함하지 않고 파일 경로를 저장합니다. 원본 파일을 이동하면 다시 열 수 없으므로 같은 위치에 보관하세요.
자막은 영상에 합성되어 저장됩니다. SRT 같은 별도 자막 파일을 생성하지 않습니다.
출력은 최대 1920×1080, 1080×1920 또는 1080×1080의 30fps H.264/AAC MP4입니다. HDR 색상 보존은 보장하지 않습니다.
원본 음성과 배경음악을 모두 큰 음량으로 사용하면 소리가 찢어질 수 있으니 음악 음량을 낮춰 주세요.
미리보기와 최종 자막의 글자 배치는 Chromium과 FFmpeg의 글꼴 렌더링 차이로 조금 다를 수 있습니다.

## 소스 코드 실행 및 Windows 빌드

Node.js 22 이상을 설치한 Windows PC에서:

```bat
npm ci
npm start
```

또는 `시작.bat`를 실행합니다. 처음에는 패키지 및 FFmpeg 다운로드를 위해 인터넷이 필요합니다.

포터블 실행 파일 빌드:

```bat
npm run dist:win
```

결과는 `dist/Frame-Studio-0.1.0-Windows.exe`입니다.

## 검증 기록

Linux 개발 환경에서 FFmpeg로 실제 MP4를 생성해 아래를 검증했습니다.
- 시작/끝 자르기와 출력 길이
- 이미지 표시 구간 전·중·후의 픽셀 색상
- 자막이 실제 출력 프레임에 합성되는지
- 짧은 배경음악의 반복과 AAC 출력
- 원본 음성 보존 및 무음 영상 내보내기

Chromium UI 자동화로 미디어 추가, 한글 자막 편집, 이미지 설정, 배경음악 추가, 프로젝트 저장/열기, 재생 및 내보내기 UI 흐름을 검증합니다. UI 테스트의 파일 대화상자 및 내보내기는 모의 API를 사용합니다. 실제 렌더링은 별도 FFmpeg 통합 테스트가 검증합니다.
GitHub Actions의 Windows runner에서 FFmpeg 통합 테스트, Electron 창·preload 초기화 및 FFmpeg 실행 확인, 포터블 패키지 생성을 수행하도록 설정했습니다. 각 실행의 성공 여부는 Actions 로그에서 확인하세요. 실제 사용자 PC에서 파일 대화상자와 긴 영상 편집을 직접 조작하는 검증은 별도로 필요합니다.

```bat
npm test
```

UI 테스트(`test/ui-check.cjs`)는 개발 환경의 `/usr/bin/chromium` 및 `ui/fixture.mp4`, `ui/fixture.png` 테스트 파일을 사용합니다.

## 구성

- `main.cjs`: 안전한 Electron 파일 접근, 프로젝트 저장/열기, FFmpeg 작업과 진행률/취소
- `preload.cjs`: 제한된 IPC 인터페이스
- `engine.cjs`: 프로젝트 검증, 이미지·ASS 자막·음성 FFmpeg 필터 생성
- `ui/`: 편집 화면과 Canvas 미리보기
- `test/`: 렌더링 및 UI 검증

## 라이선스

앱 소스 코드는 MIT입니다. FFmpeg 및 ffmpeg-static은 별도 라이선스를 따릅니다. 배포된 FFmpeg 라이선스와 빌드 정보는 앱 내 `resources/app.asar.unpacked/node_modules/ffmpeg-static/`에 있습니다. 포터블 앱은 실행 시 임시 폴더에 압축을 풉니다. 자세한 출처는 `THIRD_PARTY.md`를 보세요.
